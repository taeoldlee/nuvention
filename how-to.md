# Locale -- Live Demo Guide

## TL;DR

1. Open the app URL and click the **Demo** button (bottom-right corner)
2. Pick a user: **Josh** (operator with active projects) or **Shaurya** (creator with active projects)
3. As Josh: click a project to review drafts, or click **New Content Request** to create a brief and see AI-powered creator matching
4. Switch to **Shaurya** via Demo button to see the same projects from the creator side
5. To show onboarding: pick **Josie Chen** (new operator) or **Alex Torres** (new creator)
6. To reset everything: Demo button > **Reset Demo Data** (red button at bottom of panel)

That's it. Switch between operator/creator roles to show both sides of the marketplace.

---

## What is Locale?

Locale is a hyperlocal UGC (user-generated content) commissioning platform for restaurants, cafes, and coffee shops. It connects F&B operators with pre-vetted local content creators based on brand vibe, neighborhood fit, and content style -- then manages the entire brief-to-approval workflow in one place.

## Demo Flow 1: Operator Onboarding

*Shows how a new restaurant owner sets up their brand on Locale.*

1. Click **Demo** (bottom-right) and select **Josie Chen**
2. You land on the **operator onboarding** page ("Set up your brand")
3. **Step 1 -- Import**: Paste a Google Maps or Yelp URL to auto-fill brand info, or click **Skip** to enter manually
4. **Step 2 -- Brand**: Fill in business name, neighborhood, select vibe tags (e.g., "Cozy & Warm"), values, and content comfort zones
5. **Step 3 -- Budget**: Set a monthly content budget range using the sliders
6. **Step 4 -- Confirm**: Review all your choices, then click **Complete Setup**
7. You are redirected to the **operator dashboard** (empty state, ready to create a first content request)

## Demo Flow 2: Creator Onboarding

*Shows how a local content creator joins the platform.*

1. Click **Demo** (bottom-right) and select **Alex Torres**
2. You land on the **creator onboarding** page ("Creator Setup")

## Demo Flow 3: Content Request Lifecycle (Operator Side)

*Shows the full operator workflow, from creating a brief to reviewing drafts. Log in as Josh Rivera (Colectivo Coffee).*

### Creating a new content request

1. Click **Demo** and select **Colectivo Coffee** (Josh Rivera)
2. On the dashboard, click **New Content Request** (top-right button)
3. Fill out the brief form:
   - **Content type**: Choose from Photos, Reels, Stories, etc.
   - **Content goal**: Pick a goal like "Menu item spotlight" or "Atmosphere / ambiance"
   - **Subject**: e.g., "winter latte, morning light"
   - **Creative direction**: Optional notes on lighting, mood, angles
   - **Deliverables**: Use the +/- buttons to pick photo count, reel count (with length), story count
   - **Timeline**: Standard (5-7 days) or Rush (2-3 days)
   - **Compensation**: Flat fee, free product, discount code, or hybrid -- with budget min/max
4. The **brief template** auto-generates at the bottom (editable)
5. Click **Find Matches**
6. View the **Anonymous Shortlist**: up to 3 creator matches shown with content previews, match scores, and rationale -- creator identity is hidden
7. Click **View Details** on a match card to see the full match detail page
8. Click **Select Creator** to commission that creator -- their identity is then revealed

### Reviewing a submitted draft

1. From Josh's dashboard, click the **Ambiance photos** project (status: DRAFT_SUBMITTED)
2. View the project detail page with:
   - Project status tracker across the top
   - Brief details (deliverables, timeline, usage rights)
   - **Draft review section** showing Shaurya's submitted photos
   - Creator notes about the submission
3. Choose an action:
   - **Approve** -- marks the project as APPROVED and triggers payment
   - **Request Revision** -- enter feedback notes, sends the project back to the creator

### Viewing a revision-requested project

1. From Josh's dashboard, click the **Community photos** project (status: REVISION_REQUESTED)
2. See the previous draft with the feedback note: "Love the energy! Could we get one more shot of the barista interaction?"
3. This project is waiting for the creator (Katelyn) to submit a revised draft

## Reset Demo Data

If you have changed project statuses, approved drafts, or created new content requests during a demo, you can reset everything back to the starting state.

**Option 1 -- From the UI (recommended):**
1. Click the **Demo** button (bottom-right corner)
2. At the bottom of the panel, click the red **Reset Demo Data** button
3. Confirm when prompted
4. The page reloads with all data back to its original state

**Option 2 -- From the command line (if you have terminal access):**
- Run `npm run seed` from the project root

After resetting, click the **Demo** button to log back in as any user.

## Tips for Presenters

- **Use the Demo Switcher constantly.** It is the bottom-right floating "Demo" button. Switching between operator and creator mid-demo is the most compelling way to show the two-sided marketplace.

- **Start with the landing page.** Before logging in, the app shows the marketing landing page. Scroll through it briefly to set context on what Locale does, then click "Create a brief" to open the Demo Switcher and pick a user.

- **Show onboarding first, then the full lifecycle.** A clean narrative: Josie (new operator) onboards, then switch to Josh (returning operator) to show a dashboard with real data and the full request-to-approval flow.

- **The anonymous shortlist is a key differentiator.** When showing match results after creating a content request, emphasize that creator identity is hidden -- you evaluate content quality first, then reveal who made it.

- **Reset data between presentations.** If you ran through approval flows, the project statuses will have changed. Reset before the next audience.

- **Operator pages have warm/tan tones; creator pages have green accents.** This visual distinction helps the audience track which role they are looking at.

- **The navbar changes per role.** Operators see Dashboard, New Request, and Library links. Creators see only Dashboard. This reinforces which side of the platform you are on.

- **Content Library is operator-only.** Log in as Marie (Coralie) and click "Library" in the navbar to show approved content collected from completed projects.

- **If something breaks, just reset.** The reseed endpoint wipes and rebuilds all demo data in seconds.
